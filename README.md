Vitus это модификация для *Don't Starve Together*, добавляющая V1 из *ULTRAKILL* в качестве игрового персонажа.
В проекте реализуется собственная система **BloodReserves**, заменяющая стандартную механику голода, а также система **Integrity**, предназначенная для изменения взаимодействия персонажа с получаемым уроном.
На данный момент полностью реализован компонент **BloodReserves**. Также создан вспомогательный компонент **TemperatureCoefficients**, который получает значения температуры из игры и предоставляет другим компонентам необходимые коэффициенты для их работы. Для компонента **Integrity** заложена начальная архитектура.
Разработка временно приостановлена из-за архитектурной проблемы: необходимо корректно связать компонент **Integrity** с оригинальным компонентом **Health**, а также исключить нежелательные побочные эффекты стандартных механик игры, например получение урона от холода и жары.
